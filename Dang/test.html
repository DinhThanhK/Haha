🐛 Lỗi #1 — Deep link logic sai (gây màn hình đen)

Code gốc: if (Date.now() - start < 2500) luôn đúng vì timeout chỉ 1.5s < 2.5s → vừa mở deep link vừa redirect web ngay lập tức.

✅ Fix: Dùng document.hidden để detect app đã mở chưa.

🐛 Lỗi #2 — sessionStorage bị mất sau redirect

Một số mobile browser (Safari iOS, Samsung Internet) xóa sessionStorage sau cross-origin redirect chain. zalo_code_verifier bị mất → PKCE fail.

✅ Fix: Dùng localStorage với TTL ngắn (5 phút), không dùng sessionStorage cho verifier.

🐛 Lỗi #3 — Không có timeout / error UI

Nếu /api/zalo-token hoặc graph.zalo.me timeout → user thấy spinner mãi, không biết lỗi ở đâu.

✅ Fix: Thêm AbortController timeout 10s + hiển thị lỗi rõ ràng.

🐛 Lỗi #4 — Form data mất sau redirect

Khi Zalo redirect về, form (tên, MSSV, lớp) bị reset. User phải nhập lại.

✅ Fix: Lưu form data vào localStorage trước khi redirect, restore sau callback.

ℹ️ Lỗi #5 — id.zalo.me bắt QR (Zalo policy)

Đây là Zalo chủ động chặn login username/password trên mobile web. Không phải lỗi code. Zalo ép dùng QR nhưng lại không cho scan từ ảnh.

✅ Giải pháp: Detect khi user dùng browser (không có Zalo app) và hiện hướng dẫn rõ: "Mở Zalo app trên điện thoại → quét QR tại đây". Không cho redirect blind sang id.zalo.me nữa.
